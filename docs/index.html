MARKDOWN IN. KNOWLEDGE OUT.

一份笔记，两种学习成果。

把零散的 Markdown 学习笔记，整理成保留原标题的知识库素材，以及可用于深度学习与面试准备的专业研究报告。

快速上手

复制后，粘贴到 Codex 对话框并发送。

为 Codex 编写/个人级安装

01 / CAPABILITIES

保留笔记的主干， 整理信息的细节。

从 Markdown 中常见的杂乱元素开始，把处理规则变成可重复的工作流程。

原标题结构保留

基础版逐字保留原标题的文字、层级与顺序，正文清洗不改动原有知识框架。

图片与表格整理

文字截图提取内容，概念图描述关系，表格复刻行列与数据；无法辨识的部分如实标记。

双产物各有边界

基础版负责清洗和修正，研究版负责重构与拓展，分别保存为完整 Markdown 文档。

规则按需加载

核心流程写在 SKILL.md 中，详细规则按当前材料读取，减少无关内容进入上下文。

脚本校验与内容复核

脚本核对标题、格式与处理记录；OCR 数字、表格和研究引用仍需内容复核。

02 / TWO DELIVERABLES

整理归整理，研究归研究。

不把新增知识混入基础笔记，也不让研究报告停留在格式清洗。

产物 01 · 知识库素材

基础整理版

保持原笔记结构，让零散记录成为清晰、可检索的知识库输入。

  • 原标题、层级和顺序保持一致
  • 清理图片、链接与多余格式
  • 整理口语化表达，保留核心信息
  • 表格按标准 Markdown 复刻
用于 Dify 等知识库入库.md
产物 02 · 深度学习材料

专业研究报告版

沿着原知识主干建立完整逻辑，补齐原理、应用与技术取舍。

  • 按定义、原理、应用、对比重构
  • 查阅原始资料，补充可靠来源
  • 增加实践要点与常见错误
  • 形成面试追问与拓展思考
用于系统学习与面试准备.md

03 / THE WORKFLOW

从原笔记到成品，四步推进。

确定性检查交给脚本，内容整理与研究交给 Codex。

  1. 01

    清点输入

    冻结标题，清点图片与代码，分段读取原文。

  2. 02

    基础整理

    清理格式、处理素材，保留原信息与标题。

  3. 03

    研究重构

    组织知识体系，查证来源，补充实践与对比。

  4. 04

    校验交付

    检查结构与覆盖，复核内容，输出独立文档。

节选自 10.12 的 Tool 与 Function Calling 课堂笔记及已有产物。英文版展示对应译文。
